  reconstruit par script (J2, J5) ?
- **ADR nourri** : [ADR-001](../adr/ADR-001-socle-k8s.md)

## Protocole

Sur une machine du labo (ou chez soi, sur une machine Linux avec virtualisation). Chronométrer chaque bloc avec `time`.

```bash
# 0. Paquets (Ubuntu 24.04)
sudo apt-get install -y qemu-kvm libvirt-daemon-system virtinst cloud-image-utils
sudo usermod -aG libvirt,kvm "$USER"      # puis se reconnecter

# 1. Image cloud datée + contrôle (choisir une date dans la liste du répertoire releases/noble/)
D=release-AAAAMMJJ
cd /var/lib/libvirt/images
sudo curl -fLO "https://cloud-images.ubuntu.com/releases/noble/$D/ubuntu-24.04-server-cloudimg-amd64.img"
curl -fsSL "https://cloud-images.ubuntu.com/releases/noble/$D/SHA256SUMS" | grep ' \*\?ubuntu-24.04-server-cloudimg-amd64.img$' | sudo sha256sum -c -

# 2. Disque de la VM adossé à l'image, et configuration cloud-init
sudo qemu-img create -f qcow2 -F qcow2 -b ubuntu-24.04-server-cloudimg-amd64.img s7-spike.qcow2 30G
cat > /tmp/user-data <<EOF
#cloud-config
hostname: s7-spike
users:
  - name: s7
    sudo: ALL=(ALL) NOPASSWD:ALL
    shell: /bin/bash
    ssh_authorized_keys:
      - $(cat ~/.ssh/id_ed25519.pub)
ssh_pwauth: false
package_update: true
packages: [chrony]
EOF
sudo cloud-localds s7-spike-seed.iso /tmp/user-data

# 3. Création de la VM (réseau libvirt par défaut pour le spike ; s7-net en J2)
time sudo virt-install --name s7-spike --memory 4096 --vcpus 2 \
  --disk path=/var/lib/libvirt/images/s7-spike.qcow2,format=qcow2 \
  --disk path=/var/lib/libvirt/images/s7-spike-seed.iso,device=cdrom \
  --os-variant ubuntu24.04 --import --network network=default --noautoconsole
sudo virsh domifaddr s7-spike            # IP de la VM, puis : ssh s7@<ip>

# 4. Dans la VM : binaire k3s vérifié puis installation sans téléchargement
V=v1.35.9+k3s1; VU=${V/+/%2B}
curl -fLO "https://github.com/k3s-io/k3s/releases/download/$VU/k3s"
curl -fLO "https://github.com/k3s-io/k3s/releases/download/$VU/sha256sum-amd64.txt"
grep ' k3s$' sha256sum-amd64.txt | sha256sum -c -
sudo install -m 0755 k3s /usr/local/bin/k3s
curl -fLo install.sh "https://raw.githubusercontent.com/k3s-io/k3s/$VU/install.sh"
sha256sum install.sh     # relevé le 2026-11-05 : 8598e002e61d658fed7b7542fc6d2c66d8da6eae69e088830105d2ee1ffb6d91
time sudo INSTALL_K3S_SKIP_DOWNLOAD=true INSTALL_K3S_VERSION="$V" sh install.sh \
  --disable=traefik --disable=servicelb --secrets-encryption --write-kubeconfig-mode=0600

# 5. Vérifications
sudo k3s kubectl get nodes -o wide
sudo k3s kubectl get pods -A
free -h                                  # RAM consommée au repos
ip link show | grep mtu                  # MTU de flannel.1 attendue : MTU de l'interface - 50

# 6. Nettoyage
sudo virsh destroy s7-spike && sudo virsh undefine s7-spike --remove-all-storage
```

Si `--os-variant ubuntu24.04` est inconnu, lancer `osinfo-query os | grep -i ubuntu` et prendre la variante la plus proche.
